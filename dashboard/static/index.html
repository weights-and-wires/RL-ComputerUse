      10 · For newcomers

      What is going on?

      A language model that can see images (Qwen3-VL, four billion parameters) is shown a small web page from MiniWoB++, a suite of toy browser tasks such as “click the blue button” or “pick the date”. It answers with an action. If the page ends in the right state, it gets a reward. We nudge the model towards answers that earned more reward and repeat. That is reinforcement learning.

      The run rents one H100 GPU by the hour. A small program on a home machine creates the GPU, restarts what crashes, tracks the bill against a $50 cap, uploads the results, and deletes the GPU. If the GPU vanishes, a new one resumes from the last saved checkpoint.

      GRPO
      Group Relative Policy Optimization. For each task the model makes several attempts at once (a group). Attempts that scored above the group's average are made more likely; those below are made less likely. No separate “critic” model is needed.
      Track B
      The model sees only a screenshot and must answer with pixel coordinates, such as click(coordinate=[412, 230]), on a 0–1000 grid. Track A, used in earlier runs, instead named page elements by an ID. Track B is harder and closer to how people use a screen.
      Mixed group
      A group in which some attempts succeeded and some failed. Only these teach the model anything. If every attempt wins or every attempt loses, the group is zero-variance and is thrown away.
      Dynamic sampling
      When too many groups are zero-variance, the trainer plays more rounds to find mixed ones. “Rounds” counts how many it needed for a step.
      Held-out
      Tasks the model never practised. Doing well on them suggests it learned something general rather than memorising.
      Pool
      The set of tasks used for training. Scores here show how well practice paid off.
      EMA
      Exponential moving average: a smoothed line that gives recent steps more weight so noisy curves are readable.
      KL
      How far the model has drifted from where it started. Small is safe; a sharp rise can mean it is breaking.
      Clip fraction
      The share of updates that hit the safety limit on how much one step may change the model.
      Entropy
      How undecided the model is between answers. It usually falls as training sharpens its choices.
      Gradient norm
      The size of the update before it is applied. Spikes are a warning sign.
      Checkpoint
      A saved copy of the model's progress. Checkpoints are synced to Hugging Face so a new GPU can resume.
      Adapter (LoRA)
      A small set of extra weights trained on top of the frozen base model, which keeps training cheap.
      95% interval
      The range the true success rate probably lies in, given how many attempts were measured. Overlapping ranges mean the difference may be luck.
